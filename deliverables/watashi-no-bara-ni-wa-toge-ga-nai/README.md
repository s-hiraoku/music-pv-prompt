# 私の薔薇には棘がない — MV 成果物

Flehmann × OTO MAYUMI「私の薔薇には棘がない」のミュージックビデオです。

| ファイル | 内容 |
| --- | --- |
| `MV_1080p.mp4` | 完成版。1920×1080 / 30fps / H.264 5Mbps(2パス) / AAC 256kbps / 2分13.8秒 / 88MB |
| `MV_720p_preview.mp4` | 確認用。1280×720 / 25MB |

## コンセプト: 赤だけが色を持つ世界

世界はモノクロで、薔薇・唇・髪のメッシュの赤だけが色を持ちます。

| 区間 | 色 |
| --- | --- |
| イントロ〜Bメロ | モノクロ＋赤 |
| 1回目のサビ | 全色が戻る |
| 間奏 | 色つきとモノクロのマスが交互 |
| 夕焼けの場面 | 暖色が半分だけ戻って、また消える |
| 最後のサビ | 全色 |
| 「見納めて」以降 | 色が抜けていき、最後に赤も消える(=枯れゆくまで) |

## 映像

- **生きている静止画**: 9カットのイラストすべてを、奥行き推定(Depth Anything V2)に合わせて画素ごとにずらし、カメラが奥行きの中を動くように見せています。髪の揺れ、夜景とネオンのまたたき、タバコの煙、ろうそくと夕日の揺らぎも入れています。
- **分割画面**: スタッカートのストリングスと2ステップのリズムに合わせて、2分割、4分割、9分割に割れます。

## 歌詞

- **全行**: クリーム色の明朝(しっぽり明朝 B1)に、赤い罫線と英訳を添えて、雑誌の誌面のように組んでいます。
- **キーワード**: モーショングラフィックスで組み、すべてキャラの手前に出しています。

| 表現 | 使った言葉 |
| --- | --- |
| 帯 | ふりほどく、ユートピア、カウントダウン、間違い |
| 衝撃 | ヤケド、TIME OVER、ヒト、生き様さ |
| 上下割れ | コントラスト、弱さも / 強さも |
| 回転リング | タイトル、NO THORNS、EDEN、薔薇 |
| 残像の積み重ね | 痛々しさが、理想、トゲがない |
| 集合 / 崩壊 | タイトル、トゲがない、綺麗、薔薇、別の色 / 枯れゆくまで |
| グリッチ | 汚い夢、フラッシュバック、ヤケドするよ |

- **画面全体**: 四隅のマーク、区間名、行番号、タイムコード、ビートの点を重ねています。
- **タイミング**: 歌詞は、ボーカルを分離してから強制アライメントで1文字ずつ当てはめています。

## 使った素材

- 音源、歌詞、大人版のキャラのイラスト4枚(支給素材)
- フォント: Google Fonts(SIL Open Font License)。ライセンスは `project/mv/fonts/` に同梱しています。

支給素材(音源、歌詞、イラスト)と、そこから作った中間データは、リポジトリに入れていません。

## 作り直す手順

作り方の詳細は `project/` 以下にあります(`music-video` ブランチ)。

1. 音源を `project/assets/song.mp3`、歌詞を `project/assets/lyrics.txt`、イラストを `project/assets/adult/` に置く
2. 下準備を実行する(`project/` で実行)
   - `python3 analysis/align_mms.py`
   - `python3 analysis/build_timing.py`
   - `python3 design/riso.py`
   - `python3 design/cutout.py`
   - `python3 design/splash.py`
   - `python3 design/depth.py`
   - `python3 design/live.py`
3. 書き出す(`project/mv/` で実行)
   - `node render.mjs --cut=fresh --frames --workers=3`
   - `node render.mjs --cut=fresh --encode`
