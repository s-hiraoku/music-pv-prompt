# MV Prompt Template

AIエージェント(Claude Code、Coworkなど)にミュージックビデオを一通り制作させるための、汎用プロンプトテンプレートです。

曲、キャラクター、世界観は差し替えられる入力欄になっています。制作手順と品質チェックは固定の本文です。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `prompt/template.md` | テンプレート本体(本文は英語、入力欄と説明は日本語) |
| `examples/claude-pop.md` | 記入例(「Claude Pop」MVリメイク) |

## 使い方

1. `prompt/template.md` をコピーする
2. PART A(入力欄)の `{{...}}` をすべて埋める
3. PART B(使えるリソース)に、実行環境で本当に使えるAPIやツールだけを書く
4. 必要なら PART G(追加ルール)に作品固有のルールを書き足す
5. ファイル全体をエージェントに渡す

## 前提となる実行環境

このテンプレートは指示書です。貼るだけで動画ができるわけではありません。エージェントが以下を実行できる環境が必要です。

- 画像生成・動画生成APIの呼び出し(例: fal.ai)
- ffmpeg、Node.js、Python
- ヘッドレスブラウザ(JavaScriptアニメーションのフレーム書き出し用)
- 任意: 効果音用の音声API(例: ElevenLabs)

### 生成APIがない場合

画像・動画生成APIがなくても、[ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase) を使えば MV を作れます。キャラや背景を p5.js と p5.brush のコードで描き、ヘッドレスChromeでフレームを書き出して、ffmpegで音源と合わせる方式です(実例: [PDoomVideo](https://github.com/JohnHeibel/PDoomVideo))。必要なのは Node.js、Chrome、ffmpeg だけです。

テンプレートの PART D 末尾「コードアニメーション・ルート」に、この方式に切り替えたときの各フェーズの進め方を書いています。Phase 0 で生成APIが使えないと分かった場合も、エージェントがこのルートに切り替えます。

- 得意: 筆タッチの2Dアニメ、キャラの表情や動き、音に合わせたタイミング
- 苦手: 写実的な人物、自然な全身のダンス、本格的な口パク

## 制作フロー

★は承認ポイントです。`checkpoint` モードではここで止まり、確認を待ちます。

| Phase | 内容 | 承認 |
| --- | --- | --- |
| 0 | 環境チェック、費用見積もり | |
| 1 | 音源解析(歌詞のタイミング、ビート、セクション) | |
| 2 | コンセプトと掴み、スタイル3案 | ★ |
| 3 | キャラクターシート、セット、スタイルバイブル | ★ |
| 4 | 絵コンテ、タイミング表 | ★ |
| 5 | アニマティクス | ★ |
| 6 | 動画生成と同期の検証 | |
| 7 | 上描き、歌詞のモーショングラフィックス、効果音 | |
| 8 | 見直しと書き出し | ★ |

## 設計方針

- **タイミングは解析データが基準**：歌詞とビートのタイミングを最初に `timing.json` に出し、以降のカットや文字の出方はすべてそれに合わせます。
- **高い工程の前に全体を固める**：絵コンテとアニマティクスで全体を確認してから動画生成に進むので、組み上げてみたらちぐはぐ、という失敗を防げます。
- **数字で縛る**：予算、再生成回数、同期のズレの許容範囲を数字で決めています。
- **失敗時の代わりの手法を用意**：口パク非対応、キャラの顔や衣装のブレ、予算不足のときの逃げ道を定義しています。
- **権利への配慮**：著作権のあるキャラクターや実在の人の素材は、直接使わないルールにしています。
